A single-line fortune for a houseplant on the windowsill — kind, funny, and unmistakably about the plant itself. Written for the [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty on make.fun.

## The fortune

> A tall stranger is coming to your windowsill — do not worry, it is only your own new leaf, arriving fashionably late.

## Run

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `entry.txt` (117 characters, no trailing newline) into the output directory. Deterministic, no network, no input.
